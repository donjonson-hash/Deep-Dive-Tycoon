# Roadmap

Этапы взяты из ГДД; каждый следующий начинается только после проверки
предыдущего. Сроки — на одного разработчика.

## Now — этап 1: прототип (1–2 недели)

**Гипотеза:** связка «прокачка O₂ → нырок → ловля → продажа → яйцо →
аквариум» затягивает хотя бы на 5 минут. Если нет — охрана, рынок и зоны
игру не спасут.

**Проверка:** 3–5 человек играют без подсказок; смотрим, доходят ли до
второго нырка и сколько играют.

### Must

- [x] Каркас проекта: Rojo, Luau (strict), сервер/клиент, `Config`, тесты на Lune
- [ ] Remotes (добавим с первой фичей, которой нужен клиент → сервер)
- [x] Серая карта из кода: остров, мостик, 2 бассейна, вода (Terrain), трамплин, прилавок рынка
- [x] Индикатор глубины и зоны на экране
- [ ] Кислород: `MaxO2` / `CurrentO2`, расход по глубине (сервер, по Y), смерть при нуле, потеря улова
- [ ] Шкала O₂ с предупреждениями 25 % / 10 %
- [ ] 2 бассейна: 1-й (порог 0, +1 O₂), 2-й (порог в `Config`, +3 O₂)
- [ ] 2 зоны: Лагуна + Коралловый риф, по 3 вида рыбы, редкость
- [ ] Ловля за кислород (удержание кнопки возле рыбы), садок на 3 места
- [ ] Вес рыбы: суммарный вес улова замедляет плавание
- [ ] Продажа на рынке по **фиксированной** цене
- [ ] 1 вид яйца в гнезде в Лагуне (без охраны) → яйцо на базе растёт по таймеру → рыба
- [ ] Аквариум на базе: рыба из яйца приносит монеты раз в минуту
- [ ] Сохранение профиля (монеты, MaxO2, открытые бассейны, яйца, аквариум), сессионная блокировка
- [ ] Защита: продажа/ловля только на сервере, rate limit, проверка дистанции
- [ ] Юнит-тесты чистой логики (расход O₂, редкость, цена)

### Should (если останется время в этапе)

- [ ] Кнопка авто-прокачки (бесплатная, обычная скорость)
- [ ] Магазин снаряжения: баллон (+MaxO2) за монеты
- [ ] Простая аналитика: длина сессии, глубина, смерти

## Next — этап 2: MVP (3–4 недели)

- Рынок с биржевой ценой в пределах сервера + табло ▲▼
- 3 зоны глубины, все 5 бассейнов
- Яйца с охраной в 2 зонах, несколько видов яиц с таблицей шансов
- Участки игроков на берегу, несколько аквариумов
- Мутации рыбы, спавн редкой рыбы с оповещением сервера

**Проверка:** 20–30 тестеров играют 15+ минут без критических ошибок.

## Later

- Этап 3, альфа и баланс (2 недели): закрытый тест, анти-чит, аналитика, геймпассы и Developer Products
- Этап 4, публичный запуск (1 неделя): все 6 зон, иконка/превью, награды за лайк/избранное/группу
- Этап 5, живые обновления: сезонная рыба, ивенты, общий рынок между серверами (MemoryStoreService), PvP-кража яиц в опасных зонах

## Won't (не делаем, пока не решим иначе)

- Видео-ленты и любые награды за просмотр контента
- Офлайн-прогресс
- Своя физика плавания в прототипе — берём стандартное плавание Roblox в Terrain Water
- Финальный арт и звук до прохождения проверки прототипа
